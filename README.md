# DEC0012 - Linguagem de Programação I (2025.2)

Repositório desenvolvido para a disciplina de Linguagem de Programação I da Universidade Federal de Santa Catarina (UFSC) 🎓. Este espaço reúne as atividades, exercícios e projetos realizados ao longo do semestre de 2025.2, utilizando principalmente a linguagem C para o desenvolvimento dos conteúdos propostos na disciplina.

A disciplina tem como objetivo introduzir os fundamentos da programação e da lógica computacional, abordando conceitos essenciais como variáveis, estruturas condicionais, laços de repetição, funções, vetores, matrizes e modularização de código. Além disso, as atividades desenvolvidas contribuem para o aprimoramento da resolução de problemas e da construção de algoritmos.

Este repositório funciona como um registro das atividades realizadas durante a disciplina, reunindo desde exercícios introdutórios até implementações mais completas propostas ao longo do semestre. Os códigos presentes aqui foram desenvolvidos com finalidade acadêmica e de aprendizado, acompanhando os conteúdos trabalhados em aula.
